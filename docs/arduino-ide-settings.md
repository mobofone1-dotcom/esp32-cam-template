# Arduino IDE Einstellungen (ESP32-CAM)

Empfohlene Standard-Konfiguration in der Arduino IDE:

- **Board:** ESP32 Wrover Module
- **PSRAM:** Enabled
- **Upload Speed:** 115200
- **Serial Monitor:** 115200

## Hinweise

- Eine falsche Baudrate im Serial Monitor führt häufig zu unlesbarer Ausgabe.
- Für reproduzierbare Ergebnisse dieselben Board-Optionen in allen Test-Sketches nutzen.
